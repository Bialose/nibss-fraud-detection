# Project Visualizations

This folder contains the charts and graphical representations generated during the NIBSS Transaction Fraud Analysis project.

The visualizations were created using Python libraries, including Matplotlib, Seaborn and Pandas, to identify patterns and understand fraudulent transaction behaviour.

## Available Visualizations

### 1. Fraudulent vs. Legitimate Transactions
Shows the distribution of fraudulent and legitimate transactions in the dataset.

### 2. Fraudulent Transactions by Channel
Displays the number of fraudulent transactions across different transaction channels, including Mobile, Web, POS, Internet Banking and others.

### 3. Fraud Rate by Transaction Channel
Compares the percentage of transactions identified as fraudulent across different transaction channels.

### 4. Fraud by Merchant Category
Shows how fraudulent transactions are distributed across different merchant categories.

### 5. Fraud by Day of the Week
Examines the distribution of fraudulent transactions across the days of the week.

### 6. Fraud by Customer Age Group
Shows how fraudulent transactions are distributed across different customer age groups.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Purpose

These visualizations support exploratory data analysis (EDA) by making transaction patterns easier to understand and helping identify areas that may require further fraud investigation.

## Note

The charts are generated from the analysis performed in the `notebooks/` folder. They are saved in PNG format for easy viewing and presentation.
