# NIBSS Fraud Analysis – Notebooks

This folder contains the Jupyter Notebook and Python script used for the NIBSS Transaction Fraud Analysis project.

## Files

### 1. NIBSS_Fraud_Analysis_Enhanced.ipynb
The main Jupyter Notebook containing the complete analysis, including:
- Data inspection and cleaning.
- Missing value and duplicate checks.
- Fraudulent vs. legitimate transaction analysis.
- Fraud analysis by transaction channel.
- Fraud analysis by merchant category.
- Fraud trends by day of the week.
- Fraud analysis by customer age group.
- Data visualisations and charts.

### 2. nibss_fraud_analysis.py
A Python script containing the executable Python code exported from the Jupyter Notebook.

## Requirements

The project uses Python and the following libraries:

- Pandas
- NumPy
- Matplotlib
- Seaborn

Install the required libraries using:

`pip install pandas numpy matplotlib seaborn`

## How to Use

1. Download or clone the project repository.
2. Download the dataset from the Kaggle source provided in the main project README.
3. Place the dataset in the appropriate `data/raw/` folder.
4. Open the Jupyter Notebook and run the cells sequentially.

## Purpose

The notebooks provide a practical demonstration of data cleaning, exploratory data analysis (EDA), Python programming and data visualisation techniques applied to transaction fraud data.
